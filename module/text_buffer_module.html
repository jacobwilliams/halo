A growable text buffer, with fast number formatting, for writing large JSON files directly (see export_trajectory_json_file).

The numbers are formatted with integer arithmetic instead of formatted write statements. This is much faster, and it can run in parallel (gfortran's formatted I/O is serialized by a lock, even for internal writes). The numbers read back exactly (see add_real).

type, public ::  text_buffer

a text buffer. text is appended with the add methods, and the result is buf%s(1:buf%n). the storage is on the heap, and grows (doubles) as needed.
