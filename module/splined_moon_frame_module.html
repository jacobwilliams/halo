Splined lunar principal-axis (MOON_PA) frame: the rotation from J2000 to the frame, interpolated from a table of the frame's roll, pitch and yaw angles vs. ephemeris time (e.g., data/moon_pa_2000_2100.csv, generated with SPICE).

This is the same interpolation as the moonframe library's moon_frame_interpolater (quartic B-splines of the roll, the pitch, and the cosine and sine of the yaw angle, with the same knots), and gives identical results, but with the same pattern as splined_ephemeris_module: the spline coefficients are global variables, computed once and then only read, so all the segments (and threads) share one copy. Each moon_pa_frame object only holds its own small evaluation workspace (the interval indices and a work array, which db1val modifies), so each segment (thread) has its own. (With a copy of the coefficients in every segment, the memory grew with the square of the number of revolutions.)

private subroutine initialize_moon_pa_frame(me, filename, et0, etf)

Read the table and compute the (global) splines, for the time span [et0, etf]: the rows from the last one at or before et0 to the first one at or after etf (as in moonframe). Then the object's workspace is reset; copies of the object (allocate(..., source=...)) can be used by other threads.
